Blocs de mise en page du site de la Ville de Villefontaine.

== Description ==

Blocs fournis (catégorie « Villefontaine » de l'éditeur) :

* En-tête du site (logo, méga-menu, bouton « Vos démarches », menu mobile)
* Panneau « Vos démarches »
* Grand visuel d'accueil
* Accès en 1 clic
* Section avec titre
* Bandeau de page, Fil d'Ariane, Sommaire de la page
* Encart contact de la page (champs dans la colonne de droite de l'éditeur)
* Pages de la rubrique (tuiles automatiques vers les sous-pages)

Chaque bloc ne charge son CSS et son JavaScript que sur les pages où il est présent.

== Installation ==

1. Extensions > Ajouter > Téléverser une extension, choisir le fichier .zip, puis Activer.
2. Apparence > Villefontaine : cliquer sur « Créer le menu de départ » pour le méga-menu et pour « Vos démarches ».
3. Les menus se modifient ensuite dans Apparence > Menus.
