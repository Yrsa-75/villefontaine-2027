=== Villefontaine ===
Requires at least: 6.6
Tested up to: 7.1
Requires PHP: 8.1
Stable tag: 1.0.0
License: GPLv2 or later

Thème en blocs du site de la Ville de Villefontaine. Il gère uniquement l'apparence.
À utiliser avec le plugin « Socle Villefontaine » (en-tête, menus, blocs de mise en page).

== Gabarits ==

* Accueil (page d'accueil statique)
* Page (avec colonne latérale : sommaire et encart contact)
* Page pleine largeur
* Article, Archives, Recherche, Page introuvable

== Modèles de pages ==

À la création d'une page, WordPress propose : Page d'accueil, Page de rubrique, Page d'information.
